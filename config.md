## Root configuration object

| Name | Type | Description | |
| --- | --- | --- | --- |
| <a id="config-opt-tsnet-hostname"></a>`tsnet.hostname` | string | Hostname to use for the tsnet node.| Default: _"tsiam"_ |
| <a id="config-opt-tsnet-authkey"></a>`tsnet.authKey` | string | AuthKey can be used to authenticate the tsnet node automatically.<br>If empty, tsnet will rely on existing state in the database.|  |
| <a id="config-opt-tsnet-clientid"></a>`tsnet.clientId` | string | ClientID to use for the tsnet node.<br>Takes priority over TS_CLIENT_ID.<br>Optional query attributes can be appended, e.g. `?ephemeral=false&preauthorized=true` - without them the generated auth key is ephemeral.<br>If empty, not used|  |
| <a id="config-opt-tsnet-idtoken"></a>`tsnet.idToken` | string | IDToken to use for workload identity federation into the tailnet.<br>Takes priority over TS_ID_TOKEN<br>If empty, not used|  |
| <a id="config-opt-tsnet-idtokenfile"></a>`tsnet.idTokenFile` | string | IDTokenFile reads the IDToken from a file to use for workload identity federation into the tailnet.<br>Takes priority over TS_ID_TOKEN<br>If empty, not used|  |
| <a id="config-opt-tsnet-audience"></a>`tsnet.audience` | string | Audience to use for workload identity federation into the tailnet<br>Takes priority over TS_AUDIENCE<br>If empty, not used|  |
| <a id="config-opt-tsnet-statedir"></a>`tsnet.stateDir` | string | Directory where tsnet stores its state.<br>If empty, defaults to a folder next to the loaded config file.|  |
| <a id="config-opt-tsnet-ephemeral"></a>`tsnet.ephemeral` | boolean | If true, the tsnet node is ephemeral (not persisted in the tailnet).| Default: _false_ |
| <a id="config-opt-tsnet-advertisetags"></a>`tsnet.advertiseTags` | list of strings | Tags that should be applied to this node in the tailnet, for purposes of ACL enforcement.<br>These can be referenced from the ACL policy document.<br>Tags are generally required when using OAuth2 or workload identity federation to authenticate the node.|  |
| <a id="config-opt-tsnet-funnel"></a>`tsnet.funnel` | boolean | If true, enables Tailscale Funnel to expose the .well-known endpoints publicly.<br>This allows external OIDC clients to discover the JWKS without being on the tailnet.<br>Note: see requirements for enabling Tailscale Funnel: https://tailscale.com/kb/1223/funnel| Default: _false_ |
| <a id="config-opt-logs-level"></a>`logs.level` | string | Controls log level and verbosity.<br>Supported values: `debug`, `info` (default), `warn`, `error`.| Default: _"info"_ |
| <a id="config-opt-logs-omithealthchecks"></a>`logs.omitHealthChecks` | boolean | If true, calls to the healthcheck endpoint (`/healthz`) are not included in the logs.| Default: _true_ |
| <a id="config-opt-logs-json"></a>`logs.json` | boolean | If true, emits logs formatted as JSON, otherwise uses a text-based structured log format.<br>Defaults to false if a TTY is attached (e.g. when running the binary directly in the terminal or in development), true otherwise (e.g. in containers).|  |
| <a id="config-opt-metrics-includenodename"></a>`metrics.includeNodeName` | boolean | If true, add the caller's node name (`node` attribute) to the `tsiam_auths` metric.<br>Avoid enabling this with ephemeral nodes, as each node name creates a new time series.| Default: _false_ |
| <a id="config-opt-tokens-lifetime"></a>`tokens.lifetime` | duration | Token life time, as a Go duration<br>Must be between 1 and 60 minutes| Default: _"5m"_ |
| <a id="config-opt-tokens-allowedaudiences"></a>`tokens.allowedAudiences` | list of strings | Allowed audiences (aud claim values) for JWT tokens<br>Only audiences listed here can be requested by clients<br><br>Examples:<br>- AWS: `sts.amazonaws.com` (for OIDC federation with AWS IAM)<br>- Microsoft Entra ID (Azure AD): `api://AzureADTokenExchange` (for Workload Identity Federation)<br>- Google Cloud: Your workload identity pool audience (e.g., `//iam.googleapis.com/projects/PROJECT_ID/locations/global/workloadIdentityPools/POOL_ID/providers/PROVIDER_ID`)<br>- Custom APIs: Use your API's identifier (e.g., `https://api.example.com`)| **Required** |
| <a id="config-opt-tokens-allowemptynodecapability"></a>`tokens.allowEmptyNodeCapability` | boolean | If true, allows nodes without the audience capability to request any globally-allowed audience<br>If false (default), all nodes must have the capability explicitly granted| Default: _false_ |
| <a id="config-opt-tokens-ratelimitperminute"></a>`tokens.rateLimitPerMinute` | number | Maximum number of `/token` requests per minute per client IP (0 to disable)| Default: _60_ |
| <a id="config-opt-tokens-subjectclaim"></a>`tokens.subjectClaim` | string | Value to use for the JWT `sub` claim<br>Allowed values:<br>  - "nodeId" (default, recommended): stable Tailscale node ID<br>  - "name": MagicDNS node name (can be reused if a device is removed and re-created)<br>  - "capability": `subject` field from matching Tailscale ACL grants, falling back to the node ID if no matching grant sets `subject`| Default: _"nodeId"_ |
| <a id="config-opt-tokens-claimname"></a>`tokens.claimName` | string | Name of the custom JWT claim with the caller's Tailscale identity<br>Note: Tailscale ACL grants always use `italypaleale.me/tsiam` regardless of this setting| Default: _"italypaleale.me/tsiam"_ |
| <a id="config-opt-tokens-includecapabilities"></a>`tokens.includeCapabilities` | boolean | If true, include the caller's tsiam capability grants under `capMap` in the identity claim| Default: _false_ |
| <a id="config-opt-signingkey-storage"></a>`signingKey.storage` | string | Key storage provider<br>Allowed values: "file" (default), "memory", "AzureKeyVaultKeys", "AzureKeyVaultSecrets"| Default: _"file"_ |
| <a id="config-opt-signingkey-algorithm"></a>`signingKey.algorithm` | string | Signing algorithm to use.<br>Supported values: RS256, ES256, ES384, ES512, EdDSA.<br>Changing this does not replace an existing key.| Default: _"ES256"_ |
| <a id="config-opt-signingkey-curve"></a>`signingKey.curve` | string | Curve for EdDSA algorithm.<br>Currently only Ed25519 is supported.|  |
| <a id="config-opt-signingkey-file-storagepath"></a>`signingKey.file.storagePath` | string | StoragePath is the path to store signing key on disk.<br>The key is not encrypted on disk.| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultkeys-vaulturl"></a>`signingKey.azureKeyVaultKeys.vaultUrl` | string | VaultURL is the URL of the Azure Key Vault (e.g., https://myvault.vault.azure.net/).| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultkeys-keyname"></a>`signingKey.azureKeyVaultKeys.keyName` | string | KeyName is the name of the key in Azure Key Vault used for wrapping/unwrapping.<br>The key is unwrapped using Azure Key Vault on app startup.| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultkeys-keyversion"></a>`signingKey.azureKeyVaultKeys.keyVersion` | string | KeyVersion is the version of the key in Azure Key Vault used to wrap new signing keys.<br>If empty or "latest", the latest version of the key is used.|  |
| <a id="config-opt-signingkey-azurekeyvaultkeys-storagepath"></a>`signingKey.azureKeyVaultKeys.storagePath` | string | StoragePath is the path to store the wrapped signing key on disk.| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultkeys-tenantid"></a>`signingKey.azureKeyVaultKeys.tenantId` | string | TenantID is the Microsoft Entra ID tenant ID for authentication.<br>Required when `clientSecret` is set.|  |
| <a id="config-opt-signingkey-azurekeyvaultkeys-clientid"></a>`signingKey.azureKeyVaultKeys.clientId` | string | ClientID is the Microsoft Entra ID application (client) ID or user-assigned managed identity client ID for authentication.<br>Required when `clientSecret` is set.<br>If `clientId` and `clientSecret` are both empty, DefaultAzureCredential is used.|  |
| <a id="config-opt-signingkey-azurekeyvaultkeys-clientsecret"></a>`signingKey.azureKeyVaultKeys.clientSecret` | string | ClientSecret is the Microsoft Entra ID application client secret for authentication.<br>Requires `tenantId` and `clientId`.|  |
| <a id="config-opt-signingkey-azurekeyvaultsecrets-vaulturl"></a>`signingKey.azureKeyVaultSecrets.vaultUrl` | string | VaultURL is the URL of the Azure Key Vault (e.g., https://myvault.vault.azure.net/).| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultsecrets-secretname"></a>`signingKey.azureKeyVaultSecrets.secretName` | string | SecretName is the name of the secret in Azure Key Vault that stores the signing key.<br>The entire key is stored in Azure Key Vault.| **Required** |
| <a id="config-opt-signingkey-azurekeyvaultsecrets-tenantid"></a>`signingKey.azureKeyVaultSecrets.tenantId` | string | TenantID is the Microsoft Entra ID tenant ID for authentication.<br>Required when `clientSecret` is set.|  |
| <a id="config-opt-signingkey-azurekeyvaultsecrets-clientid"></a>`signingKey.azureKeyVaultSecrets.clientId` | string | ClientID is the Microsoft Entra ID application (client) ID or user-assigned managed identity client ID for authentication.<br>Required when `clientSecret` is set.<br>If `clientId` and `clientSecret` are both empty, DefaultAzureCredential is used.|  |
| <a id="config-opt-signingkey-azurekeyvaultsecrets-clientsecret"></a>`signingKey.azureKeyVaultSecrets.clientSecret` | string | ClientSecret is the Microsoft Entra ID application client secret for authentication.<br>Requires `tenantId` and `clientId`.|  |
